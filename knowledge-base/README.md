# Knowledge Base

This folder stores the poker study material that will guide Poker Coach's explanations.

## Folders

```text
raw/       Private PDFs, EPUBs, text exports, solver docs, screenshots, and paid material.
notes/     Your own summaries, principles, charts, and distilled concepts.
chunks/    Generated small chunks used for search/retrieval.
index/     Generated local search/vector index.
examples/  Sample hand analyses and preferred coaching outputs.
```

## Recommended Workflow

1. Put source files you legally own in `raw/`.
2. Write or generate concise notes in `notes/`.
3. Add high-quality sample coaching outputs in `examples/`.
4. Later, run an ingestion script that chunks notes/examples and builds a local index.
5. During hand analysis, retrieve only the most relevant snippets for the exact node.

## Source Material Guidance

Use this knowledge base for concepts, heuristics, and coaching voice. Avoid copying full copyrighted books into app-facing files. If you add copyrighted material to `raw/`, keep it private and local.
